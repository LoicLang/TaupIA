# Assets Directory

## Logo

Pour intégrer le logo TauIA dans l'application :

1. Placer l'image du logo dans ce dossier sous le nom `logo.png`
2. Format recommandé : PNG avec fond transparent
3. Dimensions recommandées : 128x128px ou plus (sera redimensionné automatiquement)

Le logo sera affiché dans le header de l'application avec un filtre pour l'adapter au fond noir.
